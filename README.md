# Inventory Management System

This project is a web-based platform designed to help companies efficiently manage their inventory, particularly useful for organizations with a large number of products.

## Features
- Manage products and inventory.
- Track incoming and outgoing kits.
- Pagination support for large datasets.
- Integration with TinyMCE for rich text editing.
- Security features and user-friendly alerts.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP
- **Database**: MySQL

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/T-Chaitanya/Inventory-Management-System.git
   ```
2. Set up a MySQL database and import the provided SQL file.
3. Update the `db.php` file with your database credentials.
4. Run the project on a local server (e.g., XAMPP, WAMP).

## Usage
- Access the dashboard to manage your inventory.
- Utilize pagination to handle large data efficiently.
- Manage kits (add, update, delete).
